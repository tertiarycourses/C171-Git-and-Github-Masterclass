# Lab 14 — Build a GH-900 Readiness Plan

**Exam domain:** Explore the GitHub Community (5–10%)

**Objective:** Use evidence and weighted scores to close exam-readiness gaps by domain.

## Scenario

The learner has completed the practical work and needs a targeted final revision plan.

## Deliverable

A weighted GH-900 readiness dashboard and two-day revision plan

**Tools:** Official Microsoft practice assessment, Tertiary practice exam, Excel readiness dashboard

## Detailed procedure

1. Complete the official Microsoft practice assessment under timed, distraction-free conditions.
2. Complete the Tertiary practice exam and record the date, mode and total score.
3. Enter each domain score in the Excel Exam Readiness sheet.
4. Review the weighted priority calculation and identify the top three revision domains.
5. Link each weak objective to a relevant slide, Learner Guide section and lab evidence item.
6. Redo at least one command or configuration task from each priority domain without copying the previous procedure.
7. Write a two-day study plan with specific objectives, activities and retest times.
8. Confirm the booking, personal Microsoft account, accepted ID and exam-environment requirements.
9. Schedule the next timed practice only after targeted revision and record the new result.

## Evidence workbook

Open `Lab-14-Evidence-Starter.xlsx` before you begin. Record every action, result, URL or screenshot reference, status, and reviewer note. The completed workbook is a worked example only; replace sample URLs with your own evidence.

## Acceptance criteria

- [ ] Domain scores are entered
- [ ] Priorities use weighted gaps
- [ ] Study plan links to hands-on evidence
- [ ] Exam-day requirements are confirmed
