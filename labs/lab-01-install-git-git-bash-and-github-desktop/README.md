# Lab 01 — Install Git, Git Bash and GitHub Desktop

**Exam domain:** Understand Git and GitHub Basics (25–30%)

**Objective:** Prepare and verify a safe local Git toolchain before working with repositories.

## Scenario

Northstar Learning is onboarding a new contributor on Windows or macOS and needs a repeatable setup record.

## Deliverable

A verified Git/Git Bash and GitHub Desktop installation with identity and default-branch configuration

**Tools:** https://git-scm.com/install/, https://desktop.github.com/download/, Git Bash or terminal, Excel evidence workbook

## Detailed procedure

1. Open https://git-scm.com/install/, select the operating system and download the current installer or follow the platform installation method.
2. On Windows, complete the Git for Windows installation and confirm that Git Bash is available from the Start menu; on macOS or Linux, open the installed terminal environment.
3. Open Git Bash or a terminal and run git --version; record the exact version and terminal name in Excel.
4. Open https://desktop.github.com/download/, choose the correct Windows or macOS installer and install GitHub Desktop.
5. Launch GitHub Desktop, sign in to the training GitHub account and confirm the configured Git executable and preferred editor.
6. Configure user.name, a verified or GitHub no-reply user.email, and init.defaultBranch main from Git Bash or the terminal.
7. Run git config --list --show-origin and confirm which file supplies the identity and default-branch values.
8. Create or sign in to a personal GitHub account and enable 2FA, or record the trainer demonstration where policy prevents account changes.
9. Capture the Git version, Git Bash/terminal verification, GitHub Desktop sign-in and configuration evidence in Excel without recording credentials.

## Evidence workbook

Open `Lab-01-Evidence-Starter.xlsx` before you begin. Record every action, result, URL or screenshot reference, status, and reviewer note. The completed workbook is a worked example only; replace sample URLs with your own evidence.

## Acceptance criteria

- [ ] Git version is recorded
- [ ] Git Bash or terminal works
- [ ] GitHub Desktop is signed in
- [ ] Identity and default branch are verified

## Completion evidence

Submit the completed Excel workbook together with any screenshots requested by the trainer. Never paste passwords, personal access tokens, private keys, recovery codes, or real secrets into the workbook.
