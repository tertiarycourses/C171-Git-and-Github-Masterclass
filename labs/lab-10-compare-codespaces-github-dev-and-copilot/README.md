# Lab 10 — Compare Codespaces, github.dev and Copilot

**Exam domain:** Apply Modern Development Practices (10–15%)

**Objective:** Choose an appropriate cloud editing environment and verify AI-assisted output.

## Scenario

A distributed contributor needs a consistent environment for a small documentation automation task.

## Deliverable

A dev-container configuration, environment comparison and verified Copilot-assisted change

**Tools:** Codespaces, dev containers, github.dev, GitHub Copilot or trainer demonstration, Excel workbook

## Detailed procedure

1. Open the repository in github.dev and record which editing, source-control and terminal capabilities are available.
2. Create .devcontainer/devcontainer.json from an appropriate template or instructor-provided base.
3. Commit the configuration on a branch and create a Codespace from that branch.
4. Verify the terminal, repository branch, runtime and installed tools inside the Codespace.
5. Compare github.dev, Codespaces and a local Git Bash environment against editing, terminal, runtime and persistence needs.
6. Use Copilot or the trainer demonstration to explain or improve one small validation script.
7. Review the proposed output for correctness, security and fit; change at least one item based on human verification.
8. Commit the verified change, push it and capture environment plus AI-review evidence in Excel.

## Evidence workbook

Open `Lab-10-Evidence-Starter.xlsx` before you begin. Record every action, result, URL or screenshot reference, status, and reviewer note. The completed workbook is a worked example only; replace sample URLs with your own evidence.

## Acceptance criteria

- [ ] Dev container is valid
- [ ] Environment choice is justified
- [ ] AI output is independently checked
- [ ] Verified change is committed

## Completion evidence

Submit the completed Excel workbook together with any screenshots requested by the trainer. Never paste passwords, personal access tokens, private keys, recovery codes, or real secrets into the workbook.
