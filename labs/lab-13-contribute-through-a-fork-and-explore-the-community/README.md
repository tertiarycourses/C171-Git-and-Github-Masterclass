# Lab 13 — Contribute through a Fork and Explore the Community

**Exam domain:** Explore the GitHub Community (5–10%)

**Objective:** Apply a safe fork contribution workflow and evaluate healthy community signals.

## Scenario

A learner will propose a small documentation improvement to a training repository.

## Deliverable

A fork, upstream remote, contribution branch and community-health evaluation

**Tools:** Forks, Git Bash, pull requests, licences, Sponsors, Marketplace, topics, Excel workbook

## Detailed procedure

1. Select the approved training repository and read its README, licence, CONTRIBUTING and code of conduct.
2. Fork the repository and clone the learner-owned fork.
3. Run git remote -v, add the original repository as upstream and verify origin versus upstream.
4. Fetch upstream and create docs/improve-guide from the intended upstream branch.
5. Make a small documentation improvement, review it, commit it and push the branch to origin.
6. Open a pull request to upstream or stop before submission if the exercise repository requires trainer approval.
7. Explore topics, stars, followers, organisations, GitHub Sponsors and Marketplace.
8. Evaluate the repository's licence, contribution guidance, responsiveness and sustainability signals.
9. Explain how InnerSource reuses open-source practices behind organisational access controls.
10. Record remotes, branch, PR/draft URL and community evaluation in Excel.

## Evidence workbook

Open `Lab-13-Evidence-Starter.xlsx` before you begin. Record every action, result, URL or screenshot reference, status, and reviewer note. The completed workbook is a worked example only; replace sample URLs with your own evidence.

## Acceptance criteria

- [ ] Origin/upstream are distinguished
- [ ] Contribution follows project guidance
- [ ] Branch is published to the fork
- [ ] Community signals are evaluated

## Completion evidence

Submit the completed Excel workbook together with any screenshots requested by the trainer. Never paste passwords, personal access tokens, private keys, recovery codes, or real secrets into the workbook.
