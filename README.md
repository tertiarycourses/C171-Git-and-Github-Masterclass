## About the course

Learners install a real toolchain, build commit histories, branch and merge, resolve conflicts, run pull-request reviews, automate checks with GitHub Actions, and govern repositories with security and project-management controls. The content follows the seven GitHub Foundations (GH-900) domains and includes a deep dive into Git itself — the object model, the three trees, merge vs rebase, and safe recovery with restore, revert and the reflog. It suits beginners, developers formalising their Git knowledge, and anyone planning to sit the GH-900 exam.

## Topics covered

| Topic | Focus |
| --- | --- |
| 1 · Understand Git and GitHub basics | Version control, Git areas and states, commands, accounts, GitHub Flow, Markdown |
| 2 · Work with GitHub repositories | Repository structure, branches, merges, remotes, conflicts and recovery |
| 3 · Collaborate using GitHub | Issues, pull requests, code review, discussions, notifications, Pages |
| 4 · Apply modern development practices | GitHub Actions, Copilot, Codespaces, github.dev |
| 5 · Manage projects with GitHub | Projects, views, fields, workflows, insights |
| 6 · Privacy, security and administration | 2FA, roles, rulesets, code and secret scanning, Dependabot |
| 7 · Explore the GitHub community | Open source, InnerSource, Sponsors, contributing through forks |
